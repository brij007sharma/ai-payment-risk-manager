# AI Payment Risk Manager

An AI-powered payment risk analysis system that combines
machine learning, rule-based risk assessment and an LLM
investigation layer.

## Planned Architecture

Transaction
    ↓
Feature Engineering
    ↓
ML Risk Model
    ↓
Risk Engine
    ↓
AI Investigation Agent
    ↓
Risk Explanation

## Planned Features

- Transaction risk scoring
- ML-based anomaly/risk detection
- Rule-based risk assessment
- AI-generated risk explanations
- REST API using FastAPI
- Transaction dashboard
- Model evaluation
